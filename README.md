# SMS Spam Detection

## Project Overview
This project is an SMS Spam Detection system built using Python and Machine Learning. It classifies SMS messages as Spam or Ham.

## Features
- Detects spam SMS messages
- Classifies normal (Ham) messages
- Uses Machine Learning
- Easy to use

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
- Machine Learning
- NLP

## Dataset
SMS Spam Collection Dataset

## Project Structure
SMS Spam Detection/
│── spam_detection.ipynb
│── SMSSpamCollection
│── README.md

## How to Run
1. Install Python.
2. Install required libraries.
3. Open spam_detection.ipynb in VS Code or Jupyter Notebook.
4. Run all cells.
5. Change the message and run the prediction cell.

## Output
The model predicts whether the SMS is:
- Spam
- Ham
